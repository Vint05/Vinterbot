# vinterbot

Releases of vinterbot (autofish.exe) for Windows 10 / 11. This repository holds the releases only.

- Download the latest `autofish-<version>.exe` from [Releases](../../releases/latest).
- Put it in a folder of its own and run it: your routes are saved next to it, in `routes`.
- The program updates itself at launch when a new release is out.
- Windows may warn about an unknown publisher (the exe isn't code-signed): More info -> Run anyway.
